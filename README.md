# Python Programming Practice 🚀

## About This Repository

This repository contains a collection of Python programming practice projects created to improve my problem-solving skills, logical thinking, and programming knowledge.

Each program focuses on a different Python concept, including loops, conditional statements, strings, lists, mathematical operations, and basic algorithms.

## Programs Included

### 1. Reverse a Number

Reverses the digits of a given number.

### 2. Check Prime Number

Checks whether a given number is prime or not.

### 3. Factorial of a Number

Calculates the factorial of a given number using a loop.

### 4. Palindrome String

Checks whether a word reads the same forward and backward.

### 5. Largest Number in a List

Finds the largest element from a list of numbers.

### 6. Count Even and Odd Numbers

Counts how many even and odd numbers are present in a list.

### 7. Remove Duplicates from a List

Removes duplicate elements while maintaining their original order.

### 8. Simple Interest Calculator

Calculates simple interest using the principal amount, interest rate, and time.

### 9. Multiplication Table

Generates the multiplication table for a given number.

### 10. Common Elements in Two Lists

Finds the common elements between two lists.

## How to Run the Programs

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the Python file using:

```bash
python filename.py
```

Replace `filename.py` with the name of the program you want to execute.
